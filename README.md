# django-crud-views-coreui

Current version: 0.1.0

A [CoreUI](https://coreui.io) 5 (free edition) theme for [django-crud-views](https://django-crud-views.readthedocs.io/),
with a CoreUI page shell (`django_coreui`) and a django-crispy-forms template pack (`crispy_coreui`). Work in progress.
