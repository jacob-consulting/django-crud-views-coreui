# Django CRUD Views CoreUI

Current version: 0.1.0

A [CoreUI](https://coreui.io) 5 (free edition) theme for
[django-crud-views](https://django-crud-views.readthedocs.io/). One distribution, `django-crud-views-coreui`, ships two
Django apps: `crud_views_coreui`, the theme, and `django_coreui`, a CoreUI page shell that does not depend on
django-crud-views.

This guide is under construction.
